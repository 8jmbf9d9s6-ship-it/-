# 체리키우기 V0.1

GitHub Pages에서 바로 실행되는 인트로 테스트 버전입니다.

## 업로드 방법
1. 이 폴더 안의 파일들을 GitHub 저장소 최상단(root)에 올립니다.
2. 반드시 `index.html`, `style.css`, `script.js`가 같은 위치에 있어야 합니다.
3. GitHub → Settings → Pages에서 `Deploy from a branch`를 선택합니다.
4. Branch는 `main`, Folder는 `/(root)`로 지정합니다.
5. 저장 후 생성된 GitHub Pages 주소로 접속합니다.

## 현재 구현
- 검은 화면 + 발자국 인트로
- 진동(지원 기기)
- 벚꽃 애니메이션
- CSS 체리 캐릭터
- 꼬리 흔들기
- 눈 깜빡임
- 등장/바운스/회전 모션
- 화면 터치 상호작용
- 타이틀 화면
- 게임 시작 버튼

다음 버전에서는 메인 집 화면과 밥주기 튜토리얼을 연결하면 됩니다.
